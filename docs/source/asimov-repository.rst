The asimov repository
======================

Asimov's source is developed on GitHub, at `etive-io/asimov <https://github.com/etive-io/asimov>`_,
and mirrored to GitLab at `git.ligo.org/asimov/asimov <https://git.ligo.org/asimov/asimov>`_.

The active development branch is ``main``. Release and preview branches follow a ``vX.Y-preview``
naming pattern (for example ``v0.8-preview``) while a release is being prepared.

For the code-review and contribution process, see :doc:`contributing`.
