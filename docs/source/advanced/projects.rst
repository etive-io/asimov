========
Projects
========

While the default settings for an asimov project assume that you'll want to keep all of your results files and analysis configurations together in one place, there are situations where this might not be convenient.
For example, if you want webpages which are generated by a pipeline to be available in a location which is served by a public webserver.

This page covers relocating a project's other directories; for moving the results store itself, see
:doc:`/user-guide/projects`.

Relocating working and checkout directories
---------------------------------------------

As well as ``--results`` (covered in :doc:`/user-guide/projects`), ``asimov init`` accepts:

``--working``
   Where per-analysis working directories are created. Defaults to ``working`` inside the project directory.

``--checkouts``
   Where each subject's git repository is cloned to. Defaults to ``checkouts`` inside the project directory.

``--root``
   The project's own root directory, if you don't want to create it in the current directory.

.. code-block:: console

   $ asimov init my-project --working /data/scratch/working --checkouts /data/scratch/checkouts

As with ``--results``, these can also be edited after project creation via ``.asimov/asimov.conf`` —
``--working`` sets ``[general] rundir_default`` and ``--checkouts`` sets ``[general] git_default``.

Choosing a ledger backend
----------------------------

By default a project's ledger is a single YAML file. For projects tracking a very large number of
subjects and analyses, a document-database-backed ledger is also available; see :doc:`/ledger` for the
current state of that option and its limitations.
